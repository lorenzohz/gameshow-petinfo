# Pasta de imagens de resposta

Coloque aqui as imagens que devem aparecer junto com a resposta de uma pergunta
(por exemplo, a foto que revela a resposta de um enigma).

No `data.json`, defina o campo `answerImage` da pergunta com o caminho a partir
da raiz do site, por exemplo:

```json
"answerImage": "/respostas/minha-imagem.png"
```

Se a pergunta não tiver imagem de resposta, deixe `answerImage` como `null`.
